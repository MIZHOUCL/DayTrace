## MVP 完成定义

只有同时满足以下条件，才算 MVP 完成：

1. 用户可以在 Windows 上安装并启动。
2. 用户选择工作区后，系统只扫描工作区。
3. 系统默认不读正文、不调用 AI。
4. 用户选择 diff/正文后，读取范围准确可见。
5. 敏感文件和内容有默认保护。
6. token 预算可配置，超预算会阻止请求。
7. 用户可以生成、编辑、保存 Markdown 日志。
8. 用户可以搜索项目并看到项目级/模块级图谱。
9. 用户可以保存 Codex 深度链接并导入用户主动提供的摘要。
10. 测试证明未授权内容不会进入 AI payload。
