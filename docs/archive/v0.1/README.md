# Daytrace 项目规划文档

Daytrace 是一个 local-first、privacy-first 的个人工作证据图谱与 AI 日志助手。

它从用户明确选择的工作目录、Git 变更和用户主动导入的 Codex 会话中提取“工作证据”，按项目和模块聚合，经用户确认后生成日志，并通过 Graph View 展示项目、变更、会话、主题和日志之间的关系。

## 当前结论

- 文件/Git 增量扫描、模块聚合、用户确认、日志生成和图谱展示：适合进入 MVP。
- `codex://threads/<id>` 首先作为会话引用保存；完整内容导入通过用户导出/粘贴、浏览器扩展或未来正式接口实现。
- 默认只处理元数据；读取 diff 或文件正文必须经过用户选择。
- AI 请求必须经过脱敏、token 预算和发送预览。
- 核心数据默认只保存在本地 SQLite，不要求账号和云端同步。

## 建议的第一条产品闭环

```text
选择工作区 → 扫描今日变化 → 自动聚合模块 → 用户授权读取 → 预算检查
→ 生成模块摘要 → 用户确认 → 生成 Markdown 日志 → 关联到 Graph View
```
